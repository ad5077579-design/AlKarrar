# Community ownership — ملكية المجتمع

## English

**AlKarrar Pro is community software.** It belongs to every trader and every developer who uses or improves it. It is **not** a product for sale or rent.

| Allowed | Not allowed |
|---------|-------------|
| Run it for your own trading | Sell the project or a closed fork as a product |
| Fork, modify, contribute on GitHub | Rent or lease the software to others for a fee |
| Share source under [LICENSE](../LICENSE) | Paid closed SaaS without providing source under this license |
| Build plugins and strategies | Claim exclusive ownership of the core engine |

See [LICENSE](../LICENSE) for the full terms.

## العربية

**AlKarrar Pro مشروع مجتمعي مفتوح المصدر** — ملك لكل متداول ومبرمج يستخدمه أو يطوّره.

- **مسموح:** الاستخدام الشخصي، التعديل، المساهمة، النشر العلني للشفرة تحت نفس الترخيص.
- **غير مسموح:** بيع المشروع، استئجاره أو تأجيره، أو تقديمه كخدمة مغلقة مدفوعة دون إتاحة المصدر للمجتمع.

التفاصيل القانونية الكاملة في ملف [LICENSE](../LICENSE).
